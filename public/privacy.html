Privacy, plainly stated.

Effective 21 October 2026

What we store

We store account details, uploaded or imported videos, derived frames, transcripts, conversations, notes, review activity, and operational security logs needed to provide the service.

How information is used

Your content is processed only to provide video understanding, search, collaboration, exports, security, and reliability features. We do not sell personal information or use private videos for advertising.

Storage and retention

Media is kept in private object storage and metadata is kept in the application database. New videos follow the workspace retention setting. Deleting a video removes its stored media and application derivatives through the deletion workflow.

Sharing

Content is visible only to authenticated workspace members unless you intentionally create a time-limited share link. Infrastructure providers process data only as needed to run the service.

Your choices

  • Delete individual videos and conversations.
  • Set retention periods for videos.
  • Revoke API keys and disable webhooks.
  • Request account-level access or deletion from the service operator.

Security

Production deployments use verified authentication, private storage, expiring playback links, malware scanning, account-aware limits, and isolated background processing. No system can guarantee absolute security.

Contact

Use the support contact published with the deployed service for privacy or deletion requests.
